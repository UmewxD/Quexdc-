# Quexdc — a Creative Platform

Not just another scroll-and-forget app. Quexdc is my creative-platform-in-the-making: a place for ideas, expression, curious people, and the occasional “wait, I actually built this” moment.

I’m building it in Flutter, one feature at a time. It’s still an early prototype, so some parts are local demos and some big ideas are still just ideas. That’s okay — the point is to make the good stuff work before making it huge.

## What’s in the prototype?

- A social feed, stories, moods, boards, and community spaces
- Theme palettes, styled memos, and a creator marketplace prototype
- Quests, streaks, and Easter Egg videos
- An inventor workspace for organizing idea notes
- A welcome flow for wandering around the Quexdc universe

Some features save data only on this device. The inventor notes are not encrypted, and the app does not currently provide confidential collaboration, patent filing, crowdfunding, or real-money payments. Check the in-app and project notes before using prototype features for anything sensitive.

## Run the Flutter app

The Flutter project is in [`social_media/`](./social_media/). Open that folder with Flutter tooling to explore and run the app.
